# Fingerprint Spoofing Detection using Handcrafted Features and Deep Learning

##  Project Overview

This project investigates **fingerprint spoofing detection** by comparing the performance of traditional handcrafted feature extraction techniques with modern deep learning models. The objective is to accurately classify fingerprint images as **Real** or **Altered** (Easy, Medium, and Hard) and evaluate which approach provides better discrimination for biometric authentication systems.

---

## Dataset

**Dataset:** SOCOFing (Sokoto Coventry Fingerprint Dataset)

- **Source:** https://www.kaggle.com/datasets/ruizgara/socofing
- **Image Format:** `.bmp` grayscale fingerprint images

### Dataset Structure

- **Real** – Genuine fingerprint images
- **Altered-Easy** – Slightly modified fingerprint images
- **Altered-Medium** – Moderately altered fingerprint images
- **Altered-Hard** – Highly altered fingerprint images

---

## Methodology

The project evaluates fingerprint spoof detection through three experimental approaches.

### 1. Individual Handcrafted Feature Analysis

Each handcrafted feature was extracted independently and used to train classical machine learning classifiers. This experiment evaluates the individual discriminative capability of every feature.

### 2. Combined Handcrafted Feature Analysis

Multiple handcrafted features were concatenated into a single feature vector. Classical machine learning models were then trained to analyze the effectiveness of combining complementary fingerprint descriptors.

### 3. Deep Learning Feature Analysis

Pretrained convolutional neural networks and transformer-based architectures were employed as feature extractors. High-dimensional embeddings generated by these models were used to train classical machine learning classifiers for spoof detection.
